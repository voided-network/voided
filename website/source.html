Release integrity

Source, artifact, runtime, and release state are separate proofs.

  • Tagged or committed source identifies what was intended to ship.
  • Package manifests and hashes bind native and WASM artifacts to a specific build.
  • Runtime verification checks that the selected artifact matches the package contract before use.
  • The Updates page records what is currently verified, pending, or unpublished.

Public bugs. Private vulnerabilities.
