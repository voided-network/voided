Trust the boundary, not the vibe

Security behavior you can reason about.

Voided’s strongest feature is not a magic algorithm. It is a narrow contract with explicit formats, limits, failure behavior, and ownership.

01

One source of truth

Rust owns cryptographic behavior. Native Node and browser WASM expose the same protocol instead of reinterpreting it independently.

02

Authenticate before release

Malformed structure, tampering, oversized work, and incorrect keys fail before untrusted plaintext or unbounded output is returned.

03

Stable means stable

VOF3 and the initial Recovery Deck constants are frozen contracts. An incompatible future design gets a new scheme, not a silent reinterpretation.

04

Know your trust boundary

Browser keys cannot survive fully compromised same-origin JavaScript. XSS prevention, dependency hygiene, CSP, and lifecycle locking remain application responsibilities.
