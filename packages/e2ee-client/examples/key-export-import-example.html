🔐 voideddev E2EE - Key Export/Import Demo

How it works

This demo shows how users can export their encryption key for backup and import it on other devices. The key is never sent to the server - it's handled entirely in the browser for maximum security.

Instructions

  1. Export Key: Click to see your encryption key as QR code and text. You can copy it or download it as a file.
  2. Import Key: Paste a previously exported key to restore it on this device.
  3. Rotate Key: Generate a new key (old data becomes unrecoverable).
  4. Test: Try encrypting and decrypting some text to verify everything works.
