🔐 voideddev E2EE - Customizable Key UI

Highly customizable key export/import UI components with multiple themes and styling options

🎨 Fully Customizable

Every element can be styled with custom CSS classes. No inline styles, just semantic HTML with data attributes.

📱 Responsive Design

Built-in responsive design that works on all devices. Customize breakpoints and layouts as needed.

♿ Accessibility

Full keyboard navigation, screen reader support, and high contrast mode compatibility.

🎯 Multiple Themes

Pre-built themes included, or create your own custom theme with CSS variables and classes.

🔧 Easy Integration

Simple API with callback functions for all events. Works with any framework or vanilla JS.

📦 No Dependencies

Pure vanilla JavaScript with optional QR code support. No framework dependencies required.

Usage Examples

Basic Usage

// Create client const client = new VoidedE2EEClient(); // Export key with default styling const keyExport = createKeyExport(client); await keyExport.show(); // Import key with default styling const keyImport = createKeyImport(client); keyImport.show();

Custom Styling

// Export with custom CSS classes const keyExport = createKeyExport(client, { modalClassName: 'my-custom-modal', buttonClassName: 'my-custom-button', textAreaClassName: 'my-custom-textarea', title: 'Backup Your Secret Key', onCopy: () => console.log('Key copied!'), onShare: () => console.log('Key shared!') }); // Import with custom styling const keyImport = createKeyImport(client, { modalClassName: 'my-import-modal', importButtonClassName: 'my-primary-button', warningClassName: 'my-warning-box', onSuccess: () => console.log('Key imported!'), onError: (error) => console.error('Import failed:', error) });

Theme Integration

// Apply theme to modal const keyExport = createKeyExport(client, { modalClassName: 'voideddev-modal voideddev-dark-theme', // All other classes will inherit from the theme }); // Or apply theme to specific elements const keyImport = createKeyImport(client, { modalClassName: 'voideddev-modal voideddev-colorful', buttonClassName: 'voideddev-button voideddev-colorful', textAreaClassName: 'voideddev-key-textarea voideddev-colorful' });

Advanced Customization

// Full customization example const keyExport = createKeyExport(client, { // Modal and overlay overlayClassName: 'my-overlay', modalClassName: 'my-modal', // Content sections qrContainerClassName: 'my-qr-container', textAreaClassName: 'my-textarea', keyIdClassName: 'my-key-id', warningClassName: 'my-warning', // Buttons buttonClassName: 'my-button', copyButtonClassName: 'my-copy-btn', downloadButtonClassName: 'my-download-btn', shareButtonClassName: 'my-share-btn', closeButtonClassName: 'my-close-btn', // Content options title: 'Secure Key Backup', showQR: true, showText: true, showShare: true, // Event callbacks onClose: () => console.log('Modal closed'), onCopy: () => showToast('Key copied!'), onShare: () => showToast('Key shared!'), onDownload: () => showToast('Key downloaded!') });

CSS Customization Guide

The components use semantic HTML with data attributes for easy targeting:

/* Target specific components */ [data-voideddev-component="modal-header"] { /* Modal header */ } [data-voideddev-component="key-textarea"] { /* Key input/display */ } [data-voideddev-component="button-group"] { /* Button container */ } [data-voideddev-component="qr-container"] { /* QR code area */ } [data-voideddev-component="warning"] { /* Warning/info box */ } /* Target specific actions */ [data-voideddev-action="copy"] { /* Copy button */ } [data-voideddev-action="download"] { /* Download button */ } [data-voideddev-action="share"] { /* Share button */ } [data-voideddev-action="close"] { /* Close button */ } [data-voideddev-action="import"] { /* Import button */ }

All components include comprehensive CSS examples in key-ui-styles.css with multiple themes and responsive design patterns.
